# Carrier Rating Platform

**Платформа многокритериальной оценки и рейтингования перевозчиков.**

Система превращает сырые данные о перевозках в понятный рейтинг перевозчиков. Логист загружает отчёт, настраивает сценарий оценки и запускает расчёт, а грузовладелец видит готовый ранжированный список компаний с баллами по каждому критерию и на его основе решает, кому доверить груз. Оценка опирается не на субъективное мнение, а на объективные показатели работы перевозчиков.

Методы поддержки принятия решений: **TOPSIS** и **VIKOR**, с гибкой
настройкой весов критериев через метод **SWARA**.

---

## Возможности

- **Загрузка данных** — импорт отчётов о перевозках из Excel-файлов.
- **Многокритериальный расчёт** — рейтинг перевозчиков методами TOPSIS и VIKOR.
- **Сценарии оценки** — сохранение разных конфигураций расчёта.
- **История запусков** — все проведённые расчёты с возможностью вернуться к результатам.
- **Результаты и ранжирование** — наглядный список перевозчиков с баллами и местами.
- **Экспорт** — выгрузка результатов.
- **Роли** — администратор (логист: загрузка данных, настройка и запуск расчётов) и пользователь (грузовладелец: только просмотр готовых рейтингов и истории).
- **Фоновые задачи** — тяжёлые расчёты и импорт выполняются асинхронно через Celery.
- **API-документация** — Swagger UI для REST-эндпоинтов.

## Критерии оценки перевозчиков

По умолчанию система использует 8 критериев. 

| # | Код                   | Описание                          | Тип       |
|---|-----------------------|-----------------------------------|-----------|
| 1 | `on_time_rate`        | Своевременность доставки          | benefit   |
| 2 | `cancellation_rate`   | Доля отменённых рейсов            | cost      |
| 3 | `cargo_safety_rate`   | Сохранность груза                 | benefit   |
| 4 | `accident_rate`       | Аварийность                       | cost      |
| 5 | `tracking_compliance` | Доля рейсов с GPS-трекингом       | benefit   |
| 6 | `pod_rate`            | Доля рейсов с подтверждением (POD)| benefit   |
| 7 | `feedback_score`      | Средняя оценка клиентов           | benefit   |
| 8 | `rate_per_km`         | Средняя ставка за километр        | cost      |

## Быстрый старт (Docker)


**1. Установите Docker**

**2. Запустите приложение**

В терминале, открытом в папке проекта:

```bash
docker compose up --build
```


**3. Откройте приложение**

```
http://localhost:8000
```

## Структура проекта

```
.
├── docker-compose.yml      # описание сервисов (web, worker, db, redis)
├── Dockerfile              # образ приложения
├── requirements.txt        # зависимости Python
├── run.py                  # точка входа веб-приложения
├── worker.py               # точка входа Celery-воркера
├── config.py               # конфигурация
├── migrations/             # миграции базы данных (Alembic)
└── src/
    ├── __init__.py         # фабрика приложения (create_app)
    ├── models.py           # модели данных
    ├── seed.py             # стартовые данные (пользователи, критерии)
    ├── auth.py             # авторизация и декораторы доступа
    ├── routes/             # маршруты: web, api, auth
    ├── services/           # бизнес-логика (расчёты, сценарии, импорт)
    ├── repositories/       # доступ к данным
    ├── schemas/            # валидация и сериализация
    ├── templates/          # HTML-шаблоны
    └── static/             # CSS и статика
```
